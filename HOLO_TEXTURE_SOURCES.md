# Holo texture sources

LR3.20 replaces procedural dot stand-ins with real image textures for the holo families that depend on raster foil/glitter/cosmos layers.

## Galaxy / Cosmos
- **The Great Carina Nebula** by Dylan O'Donnell / deography.com
- Wikimedia Commons: https://commons.wikimedia.org/wiki/File:The_Great_Carina_Nebula.jpg
- License: CC0 / public domain
- Used as the moving cosmos background under the rainbow field.

## Glitter
- **Glitter Foil Texture Background** by Martina Stokow
- Public Domain Pictures: https://www.publicdomainpictures.net/en/view-image.php?image=495267&picture=glitter-foil-texture-background
- License: CC0 / public domain
- Used by Amazing Rare and VMAX as a real glitter/sparkle texture.

## Foil surface texture
- **Foil002 PREVIEW** by ambientCG / Lennart Demes
- Wikimedia Commons: https://commons.wikimedia.org/wiki/File:Foil002_PREVIEW.png
- License: CC0 1.0
- Used by Amazing Rare, V Full Art and VMAX as the physical foil/texture layer.

## Reference implementation
- Simey / pokemon-cards-css: https://github.com/simeydotme/pokemon-cards-css
- Reference only for the layer/blend approach. LR3.20 uses Night Ledger's own selectors, interaction variables and independently sourced public-domain textures.
